# An-lise-de-Neg-e-Gest.TI
Projeto da matéria de Análise de negócios e Gestão de TI

📌 Projeto em Destaque

1. 🧴 Lumina Tech & Care — Arquitetura de TI & Indústria 4.0

Descrição: Reestruturação de TI e modelagem de processos para uma indústria cosmética de skincare personalizado. O sistema integra CRM, ERP, MES e IoT no chão de fábrica para eliminar ilhas de informação e garantir conformidade regulatória (ANVISA RDC nº 894 e 752/2022).

Principais Tecnologias Estudadas: BPMN (Bisagi), COBIT, IoT (Sensoriamento/Balanças Digitais), PID (Controle de Desvios), Visão Computacional / IA.
